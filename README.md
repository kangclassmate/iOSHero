# 常见问题
问：为什么在线安装之后(下载进度条走完)显示<b>无法下载</b>？<br/>
答：请在安装App前核验自己的iOS版本是否匹配，如果匹配那么请修改当前网络的DNS（修改详细教程请自行百度）再进行下载。<br/>

问：为什么安装成功后打开需要登录ID/iTunes账户？<br/>
答：如出现此类情况很可能出现在“正版应用”，如果您下载的是爱思正版，则建议你连接电脑爱思助手下载爱思助手App后重新尝试；如果不是爱思版本，则可能是个人签名版本，这时请在iOSHero交流群里询问解决方案。<br/>
